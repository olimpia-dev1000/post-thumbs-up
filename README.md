# Simple Post Thumbs Up
A WordPress plugin that adds thumbs up functionality to posts using IP tracking.

## Description
This plugin adds a thumbs up button to your posts, allowing users to like content once per IP address.  
No cookies required!

## Installation


## From GitHub:

1. Click the "Code" button and download the ZIP file
2. Go to WordPress Admin > Plugins > Add New > Upload Plugin
3. Upload the ZIP file
4. Activate the plugin

## Using Git:

```
cd wp-content/plugins/
git clone https://github.com/olimpia-dev1000/simple-post-thumbs-up.git
```


## Usage:

Add the thumbs up button to your posts using the shortcode:

```
[thumbs_up_button]
```

## Features

* One like per IP address
* No cookies required
* Works with Oxygen Builder
* Simple shortcode implementation
* AJAX-powered interactions

## Requirements

WordPress 5.0 or higher  
PHP 7.2 or higher
